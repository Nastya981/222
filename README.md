# Сервис управления рассылками

Курсовая работа: Django-приложение для управления рассылками сообщений.

## Часть 1: Разработка сервиса

### Функционал
- Управление получателями (CRUD)
- Управление сообщениями (CRUD)
- Управление рассылками (CRUD)
- Отправка рассылок по требованию
- История попыток отправки
- Главная страница со статистикой

### Модели
- Recipient — получатель рассылки
- Message — сообщение
- Mailing — рассылка
- Attempt — попытка отправки

## Запуск
```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
